\# Swahili Phishing Detection



A machine learning system for detecting phishing in Swahili-language SMS and online messages, with a focus on Tanzanian context.



\## Project Status



\*\*Phase:\*\* Phase II Dissertation (DIT Master's Programme, 2025/26)

\*\*Current stage:\*\* Data collection and analysis (Seminar I prep)



\## Dataset



Combined dataset of 2,408 messages from three sources:

\- \*\*BongoSCAM\*\* (Henry Dioniz, 2024) — 1,377 real Tanzanian SMS messages

\- \*\*Synthetic phishing\*\* — 331 templated variations across 5 attack categories

\- \*\*Swahili News\*\* (HuggingFace community-datasets/swahili\_news) — 700 legitimate text examples



Class balance: 1,211 phishing / 1,197 legitimate (≈1.01:1)
